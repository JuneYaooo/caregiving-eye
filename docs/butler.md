# 米执事（Mi Butler）——身份与能力设计

> 给照护系统一个身份：他不是一堆检测器的集合，而是一位**常驻家中的 AI 执事**。
> 本文档定义他的名字、值班制度、能力清单、说话方式与施工分期。

## 一、身份设定

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 名字 | **米执事**（Mi Butler） | `.env` 的 `BUTLER_NAME` 可改（"张叔"、"管家婆"随你） |
| 称呼对象 | **老爷** | `OWNER_TITLE` 可改（老板/主人/妈） |
| 性格 | 简短、克制、分级通报、有问必答 | 报喜也报忧，不说废话 |
| 提醒方式 | 本地 `events/`；可联动飞书 / 微信 / QQ 机器人 | 可结合 OpenClaw / Hermes / WorkBuddy / ZCode / Claude Code / Codex 等 AI 工具配置渠道与事件转发；本项目不内置平台机器人 |

## 二、值班制度（模式引擎）

执事按"家里有没有人"切换值守重点，支持自动切换 + 日程表 + 主人指令三种来源
（优先级：指令 > 日程 > 自动；自动切换带迟滞防抖）。

| 模式 | 进入条件 | 执事在做什么 |
| --- | --- | --- |
| **无人值守 AWAY** | 无人出现 >10 分钟（或日程/指令） | 防火、防盗、防异常声响；目标出现即跟踪存证 |
| **在家照护 HOME** | 有人出现 >2 分钟 | 跌倒/久卧/滞留/夜间徘徊/作息，儿童危险升级 |
| **宠物-only PET** | 只检测到猫（人全部离开） | 猫安全+拆家+活动记录，人形事件按 AWAY 逻辑保留 |
| **夜间加强 NIGHT** | 日程（如 23:00–07:00） | 音频灵敏度上调；卧室外徘徊立即通报；非急事免打扰 |

模式切换本身也是事件：`〔执事〕23:01 进入夜间值守。有事我叫你。`

## 三、能力矩阵

状态说明：**已实现** = 代码已接入 `care_v2.py`，仍需按自家机位校准；**规划** = 尚未编写。
各能力的代码在 `abilities/` 目录，一个文件一种能力。

### 无人值守 AWAY

| 能力 | 做法 | 开源依赖 | 状态 |
| --- | --- | --- | --- |
| 入侵检测 | 无人 / 宠物模式下确认的人形 → 抓拍 + 前后短视频 + 可选云台跟踪 | YOLOv8n、可选 [ByteTrack](https://github.com/roboflow/supervision) | 已实现 |
| 火焰 / 烟雾 | 6 秒内 ≥3 帧命中算疑似；持续 15 秒或同时听到报警器声才升为急报 | [D-Fire](https://github.com/gaiasd/DFireDataset) 训练的 [YOLOv8n](https://huggingface.co/rabahdev/fire-smoke-yolov8n) | 已实现 |
| 烟雾报警器声 | YAMNet `Smoke detector, smoke alarm` / `Fire alarm` 类 | [YAMNet ONNX](https://huggingface.co/audiomagic/yamnet-onnx) | 已实现 |
| 玻璃碎裂 / 撞击 | YAMNet `Glass` / `Shatter` / `Smash, crash` | 同上 | 已实现 |
| 长时间无人 | 超过 `ABSENCE_MIN` 分钟未见人 | — | 已实现 |
| 事件视频存证 | 环形缓冲保留事件前 10 秒，再录 15 秒，写成 mp4 | OpenCV | 已实现 |

### 在家照护 HOME

| 能力 | 做法 | 开源依赖 | 状态 |
| --- | --- | --- | --- |
| 老人跌倒 | 姿态状态机：站立 → 2.5 秒内倒卧 | YOLOv8n-pose | 已实现，升级 ST-GCN 为规划 |
| 倒地久卧 | 倒卧计时 | — | 已实现 |
| 突发不适 | 休息区外倒卧、倒卧无动作、倒卧抽动、近期跌倒、呼喊呻吟声、卫生间倒卧；**两个信号同时成立才急报** | YOLOv8n-pose、YAMNet | 已实现 |
| 长时间无动作 | 白天、非休息区超过 `STILL_ALERT_MIN` 分钟无明显动作 | YOLOv8n-pose | 已实现 |
| 儿童危险 | 身体比例 + 可选身高带判定儿童；进入 `danger_zones` 且 `ADULT_NEAR` 范围内无成人 → 急报；只有孩子没有大人超过 `CHILD_ALONE_MIN` → 提醒 | YOLOv8n-pose | 已实现 |
| 婴儿哭声 | YAMNet `Baby cry, infant cry` | YAMNet | 已实现 |
| 卫生间久滞 / 夜间离床 | 区域计时 / 夜间区域规则 | — | 已实现 |
| 作息偏离 | 按小时活跃度与历史对比 | — | 规划（活动数据已在累计） |

> 摄像头不诊断疾病，检测的是“行为异常”，升级为需要人来查看的急报。

## 四、执事话术（通报风格示例）

```
〔值守〕11:42 客厅出现移动目标，已转向跟踪并存证。若是您本人回家，
        回复"是我"即可，我退下。

〔急报〕09:15 判断老人在客厅跌倒，至今 3 分钟未起身，已抓拍。
        请立即查看！回复"没事"解除本次告警。

〔宠物〕今日主子活动 41 次：猫爬架 18、沙发 12、餐桌 7（拆家嫌疑 2 次，
        14:22 与 19:05，clip 已存）。热力图见附图。晚饭后安静，一切正常。

〔晨报〕昨夜 23:00–06:30 无异常声响；06:40 起床，今晨活动 9 次，作息正常。
        当前模式：在家照护。
```

指令集（首版）：`是我` / `没事` / `看看客厅`（转向+回图）/ `静音1小时` / `日报` / `模式 away|home|pet|night`。

## 五、配置增量（.env）

```
BUTLER_NAME=米执事
OWNER_TITLE=老爷
# 值班日程 (分号分隔, 时段:模式)
MODE_SCHEDULE=23:00-07:00:night
# 儿童
HAS_CHILD=1
CHILD_HEIGHT_BAND=0.0-0.42   # 站立时身长/画面高, 机位标定后填
# 危险区写在 zones.json 的 danger_zones
# 完整列表见 .env.example
```
