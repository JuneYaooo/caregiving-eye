# 米执事（Mi Butler）——身份与能力设计

> 给照护系统一个身份：他不是一堆检测器的集合，而是一位**常驻家中的 AI 执事**。
> 本文档定义他的名字、值班制度、能力清单、说话方式与施工分期。

## 一、身份设定

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 名字 | **米执事**（Mi Butler） | `.env` 的 `BUTLER_NAME` 可改（"张叔"、"管家婆"随你） |
| 称呼对象 | **老爷** | `OWNER_TITLE` 可改（老板/主人/妈） |
| 性格 | 简短、克制、分级通报、有问必答 | 报喜也报忧，不说废话 |
| 提醒方式 | 本地 `events/`；可联动飞书 / 微信 / QQ 机器人 | 通过 OpenClaw / Hermes 另行配置渠道与事件转发；本项目不内置平台机器人 |

> 声明：个人开源项目，与小米公司无关；名字里的"米"仅致敬米家生态。

## 二、值班制度（模式引擎）

执事按"家里有没有人"切换值守重点，支持自动切换 + 日程表 + 主人指令三种来源
（优先级：指令 > 日程 > 自动；自动切换带迟滞防抖）。

| 模式 | 进入条件 | 执事在做什么 |
| --- | --- | --- |
| **无人值守 AWAY** | 无人出现 >10 分钟（或日程/指令） | 防火、防盗、防异常声响；目标出现即跟踪存证 |
| **在家照护 HOME** | 有人出现 >2 分钟 | 跌倒/久卧/滞留/夜间徘徊/作息，儿童危险升级 |
| **宠物-only PET** | 只检测到猫（人全部离开） | 猫安全+拆家+活动记录，人形事件按 AWAY 逻辑保留 |
| **夜间加强 NIGHT** | 日程（如 23:00–07:00） | 音频灵敏度上调；卧室外徘徊立即通报；非急事免打扰 |

模式切换本身也是事件：`〔执事〕23:01 进入夜间值守。有事我叫你。`

## 三、能力矩阵

### 无人值守 AWAY

| 能力 | 算法 | 状态 |
| --- | --- | --- |
| **入侵检测** | AWAY 模式 person 检出 → ByteTrack 锁定 → **ONVIF 云台跟踪** → 30s 存证 clip | 待建 |
| **火灾/烟雾** | 视觉：D-Fire 预训练 YOLOv8n（fire/smoke 两类）+ 多帧持续（≥3 帧/5s，防阳光闪烁误报）；音频：YAMNet `Smoke detector alarm` 类（烟警器的 4kHz 哔哔声极好认）；**视听双确认才拉最高级警报** | 待建 |
| **玻璃碎/异响** | YAMNet（P1 音频层） | P1 |
| **猫独自在家安全** | 猫长时间静止/异常嘶叫/禁区 | 复用 PET 能力 |

### 在家照护 HOME

| 能力 | 算法 | 状态 |
| --- | --- | --- |
| 老人跌倒 | 姿态状态机 →（P2）ST-GCN，见 [algorithms.md](algorithms.md) | P0 |
| 倒地久卧 | 静止计时器 | 已有 v0 |
| 突发疾病* | **复合信号**：跌倒不升 + 异常位置久卧 + 挣扎动作（P2 动作识别）+ 呻吟音频 + 作息偏离，多信号合一升级 | P1–P2 |
| 儿童危险 | 身高带分类（bbox 高/帧高按机位标定）+ 危险 zone（灶台/窗台/大门）+ **无成人伴随**（最近成人 track 距离 >2m）→ 通报 | 待建 |
| 卫生间久滞/夜间徘徊/无人出现 | 定时器族 | P0 |

> *诚实边界：摄像头不诊断疾病，检测的是"行为异常与跌倒"，升级为需要人来查看的急报。

### 宠物 PET

| 能力 | 算法 | 状态 |
| --- | --- | --- |
| 禁区/拆家 | zone + 驻留 +（P1）抓挠声辅助，事件自动存 15s clip | 已有 v0 + 待建 clip |
| **活动热力图** | 检测中心按 26×15 网格日累积 → 伪彩色叠加在底图上；附 zone 计数表 | 待建，零训练 |
| **活动日报** | events 时间线 → 模板晨报/晚报（可选 LLM 润色成白话） | 待建 |

## 四、执事话术（通报风格示例）

```
〔值守〕11:42 客厅出现移动目标，已转向跟踪并存证。若是您本人回家，
        回复"是我"即可，我退下。

〔急报〕09:15 判断老人在客厅跌倒，至今 3 分钟未起身，已抓拍。
        请立即查看！回复"没事"解除本次告警。

〔宠物〕今日主子活动 41 次：猫爬架 18、沙发 12、餐桌 7（拆家嫌疑 2 次，
        14:22 与 19:05，clip 已存）。热力图见附图。晚饭后安静，一切正常。

〔晨报〕昨夜 23:00–06:30 无异常声响；06:40 起床，今晨活动 9 次，作息正常。
        当前模式：在家照护。
```

指令集（首版）：`是我` / `没事` / `看看客厅`（转向+回图）/ `静音1小时` / `日报` / `模式 away|home|pet|night`。

## 五、配置增量（.env）

```
BUTLER_NAME=米执事
OWNER_TITLE=老爷
# 值班日程 (分号分隔, 时段:模式)
MODE_SCHEDULE=23:00-07:00:night
# 儿童身高带 (bbox高/帧高, 机位标定后填)
CHILD_HEIGHT_BAND=0.0-0.42
# 危险 zone (zones.json 扩展 type: danger)
```

## 六、施工分期

| 期 | 内容 | 工作量 |
| --- | --- | --- |
| B0 | 模式引擎（自动切换+日程+指令）+ 执事话术改造通报层 | 0.5 天 |
| B1 | 热力图 + 晨报/晚报生成 | 1 天 |
| B2 | 无人值守：入侵跟踪存证 + 火灾视听双通道（D-Fire 模型 + YAMNet 烟警） | 2 天 |
| B3 | 儿童危险规则 + 疾病复合信号升级 | 1–2 天 |
| B4 | 扬声器喊话/对讲（miss 双向音频，先"威慑喊话"后双向） | 1 天（可选） |

依赖关系：B2/B3 的音频部分依赖 [algorithms.md](algorithms.md) 的 P1；跌倒升级依赖 P2。
